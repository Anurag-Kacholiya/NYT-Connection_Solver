Baseline-0 Model Architecture

Global Vector Embedding & K-Means Optimization
Input Layer
16 Game Board Tokens
The raw textual input consists of 16 distinct words or short phrases provided by the NYT Connections daily puzzle (e.g., BUCK, SINGLE, AIRPORT).
Feature Extraction
GloVe 300d Web Crawl Embeddings
Each token is mapped to a high-dimensional continuous vector space. We use Global Vectors (GloVe) trained on 840B tokens, converting semantic meaning into 300-value numerical coordinates. Multi-word phrases are resolved via vector averaging.
Unsupervised Learning
K-Means Centroid Optimization
An iterative algorithm (k=4) identifies cluster centroids. However, instead of simple greedy assignment, we then apply a Size-Constrained Optimization layer to ensure game compliance.
Prediction Output
Linear Sum Assignment Result
The Hungarian Algorithm solves a bipartite matching problem between words and cluster "slots", ensuring that every final group contains exactly 4 words.
