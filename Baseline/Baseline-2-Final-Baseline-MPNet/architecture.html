Final Baseline Architecture (MPNet)

Neural Contextual Embeddings & Hungarian Optimization
Input Phase
16 Puzzle Tokens
The system takes the 16 words from the Connections board as input (e.g., LEAD, TIN, BOTTLE, JAR).
Deep Embedding
all-mpnet-base-v2 Context Layer
Words are mapped to a 768-dimensional space using a pre-trained Transformer model. We also calculate Lexical Similarity (character n-grams) to catch syntactic patterns, resulting in a dual-similarity matrix.
Preprocessing
Double Centering Transformer
To improve clustering quality, the similarity matrix is Double Centered (subtracting row/column means). This highlights the relative uniqueness of word relationships within the specific 16-word board context.
Constraint Solving
Hungarian Algorithm (Size-Constrained)
Unlike standard K-Means, this layer enforces a Quadratic Assignment that guarantees exactly 4 groups of 4. It treats word-grouping as a bipartite matching problem to minimize total semantic cost.
