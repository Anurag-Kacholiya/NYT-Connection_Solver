# NLP Connections Solver: Evaluation Report

## 1. Evaluation Results

The solver was evaluated using two different sampling methods on the historical NYT Connections dataset.

### 1.1 Random Evaluation (100 Randomly Sampled Games)
- **Number of games completely solved**: 16 / 100 (16.0%)
- **Total number of groups completely solved**: 134 / 400 (33.5%)
- **Number of groups in which 3 words correct and 1 wrong**: 174 / 400 (43.5%)
- **Number of games with exactly 2 solved groups and 2 one-away groups**: 10 / 100 (10.0%)

## 2. Methodology

The system utilizes a 4-feature hybrid similarity model that constructs independent distance/similarity matrices, which are then aggregated into a single unified matrix for group searching.

### Feature Engineering
1.  **Semantic Similarity (Dense Embeddings):** Uses `all-mpnet-base-v2` to capture broad topical relations. (Weight: 0.55)
2.  **Lexical Similarity (Character N-Grams):** Uses Jaccard Similarity on n-grams to catch orthographic wordplay like rhymes or shared prefixes. (Weight: 0.15)
3.  **Knowledge Graph 1: WordNet:** Applies Wu-Palmer Similarity to reward exact synonyms or hypernyms. (Weight: 0.15)
4.  **Knowledge Graph 2: WikiData:** Queries for explicit entity properties (e.g., "NBA teams") to provide a grouping boost for specific real-world knowledge. (Weight: 0.15)

### Solver Algorithm
The solver performs a **Greedy Combinatorial Search** across all possible subsets of 4 words, scoring them based on the sum of pairwise similarities in the unified matrix. It iteratively selects the highest-scoring disjoint subsets while simulating the game's "4 lives" mechanism.

## 3. Shortcomings

While the solver demonstrates significant improvement over baseline models, several limitations remain:

- **Abstract Wordplay:** The system can struggle with highly abstract wordplay or "lateral thinking" connections that aren't well-represented in semantic embeddings or structured knowledge graphs.
- **Obscure Cultural References:** Connections relying on niche pop culture or very recent events may be missed if they are not yet indexed in WikiData.
- **Post-hoc Reasoning Divergence:** The post-hoc reasoning generated by the local LLM (`flan-t5-base`) can occasionally diverge from the underlying mathematical justification, leading to explanations that, while plausible, may not perfectly reflect the model's "intent."
- **Greedy Search Limitations:** The greedy nature of the search algorithm means it might commit to a high-scoring but incorrect group early on, which can then prevent it from finding the correct overall partition.
